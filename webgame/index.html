🎓 The Workshop Behind This Game

This game is the playground of the Wild Drone LLM Workshop — a hands-on course that teaches students how to build AI agents that understand natural language and control robotic systems. The goal is to make LLM concepts tangible: instead of abstract demos, students drive a drone through natural-language commands and watch the consequences in real time.

  • How LLMs work — tokens, context, prompting, and why models are limited to their training data.
  • Tool calling & function execution — giving an LLM external functions (move(), turn(), take_picture()) so it can act on the world.
  • Natural language → robot commands — translating free-form instructions into structured actions.
  • Prompt engineering — system prompts that shape agent behaviour and reliability.
  • Agent design — single-action vs. multi-action agents, sensor feedback, and autonomous decision loops.

The notebooks (part1-travel-agent.ipynb, part2-drone-safari.ipynb) build a command agent for this exact game using Python + LiteLLM — try the Colab editions in the colab/ folder of the repository.

🚁 The Game

Navigate a drone across a 12×12 safari park and photograph 3 animal species (🦓 zebra, 🐘 elephant, 🦌 oryx) with only 5 pictures.

  • 🌳 Avoid trees and park boundaries — crashing ends the mission.
  • 📸 An animal must be exactly 2 cells away, in the direction you face, for a valid photo.
  • 🚧 A tree between you and the animal blocks the shot.
  • 😱 Getting too close (adjacent) scares the animal away — the mission fails.
  • 🏆 Photograph all three species to win. Run out of pictures and it's game over.
  • 🔋 The Sensors button shows what the drone detects: animal GPS positions, nearby trees and boundaries — just like the sensor tools the workshop agent uses.

🎮 How to Play

  • Keyboard: ↑/↓ move · ←/→ turn · Space/Enter photo · R restart · Q quit
  • On-screen: D-pad buttons for move/turn, 📷 for photo, 🔋 Sensors for the scan
  • Difficulty: Easy / Medium / Hard changes tree placement and park layout
  • Watch the Flight Log for live feedback — the same messages the LLM agent would receive in the notebooks.

🤖 Agent API (what the LLM uses)

game.move("forward")   # forward | backward | left | right
game.turn("left")      # left | right
game.take_picture()    # capture photo

Every call returns a message the agent can read — exactly how the workshop's natural-language command agent learns to fly this drone.
